# 🌦️ Weather IQ – Weather Forecast Web Application

## 📖 Overview

**Weather IQ** is a responsive weather forecasting web application built using **HTML, CSS, and JavaScript**. It provides users with real-time weather information and a clean, user-friendly dashboard to monitor current weather conditions and a 7-day weather forecast.

This project was independently designed and developed as part of my **Remote Web Development Internship at Thiranex**, helping me strengthen my front-end development skills and gain hands-on experience with API integration and responsive web design.

---

## ✨ Features

* 🌍 Search weather by city
* 🌡️ Real-time temperature updates
* 💧 Humidity information
* 💨 Wind Speed
* 🌬️ Atmospheric Pressure
* 🌿 Air Quality Index (AQI)
* 📅 7-Day Weather Forecast
* 📱 Fully Responsive Design
* ⚡ Fast and User-Friendly Interface
